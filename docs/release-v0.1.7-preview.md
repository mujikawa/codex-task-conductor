# Task Conductor v0.1.7-preview

This documentation update reduces repeated tracker publication and unnecessary
coordinator transfers. Issue bodies retain stable scope and compact current state;
meaningful progress uses incremental comments and linked evidence. Context-window
changes alone do not create an ownership boundary.

Required candidate gates, independent acceptance, authorization, worker isolation,
and delivery/Ops measurement cutoffs remain intact. Experimental context management
is optional; no token savings or new live-pilot result is claimed for this release.

Validation: skill metadata validation, local Markdown links, and git diff --check.
